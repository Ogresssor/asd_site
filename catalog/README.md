# Раздел «Продукция» — исходные данные и структура

Источник: архив заказчика из 16 файлов `.docx` (брифы по направлениям).
Из них собрано: **9 разделов, 33 подраздела, 68 позиций, 68 изображений**.

## Состав папки

- `structure.md` — дерево разделов/подразделов/позиций в читаемом виде (для согласования с заказчиком).
- `catalog.csv` — та же структура таблицей (`;`, UTF-8 BOM — открывается в Excel двойным кликом).
  Колонки: Раздел, Подраздел, Позиция, Бренды, Изображение, Код (symbol code), Источник.
- `catalog.json` — то же для скрипта импорта.
- `images/<раздел>/<подраздел>/<позиция>.png|jpeg` — картинки, извлечённые из .docx
  и переименованные по позиции. Имена файлов = `symbol code` позиции.

## Что в данных есть и чего нет

Есть: название позиции, бренды, одно фото.
Нет: артикулов, цен, технических характеристик, описаний, документации.

Поэтому каталог строится как **витрина категорий**: карточка = тип оборудования,
а не конкретный SKU. Цены и корзина не подключаются, целевое действие — «Запросить КП».
Когда появится прайс/выгрузка из 1С, эти же разделы наполняются товарами без
перестройки дерева.

## Как заливать в Аспро: Приоритет 2.0

1. Инфоблок каталога `aspro_priority_catalog`, разделы — два уровня
   (Раздел → Подраздел), позиции — элементы.
2. Свойства элемента, минимум:
   - `BRAND` — привязка к инфоблоку «Производители» (множественное). Колонка «Бренды»
     в CSV — строкой; перед импортом бренды нужно завести элементами справочника.
   - `MORE_PHOTO` — доп. фото (на будущее).
   - Детальная картинка — из колонки «Изображение».
3. Symbol code раздела/элемента брать из колонки «Код» — получаются ЧПУ вида
   `/catalog/nasosnoe-oborudovanie/cirkulyacionnye-nasosy/`.
4. После заливки — очистить кэш Аспро (Настройки продукта → Аспро: Приоритет 2.0 → Очистить кэш).

## Открытые вопросы к заказчику

1. Раздел «Энергосбережение» из архива разнесён в «Приборы учёта и КИПиА»
   (расходомеры, теплосчётчики, датчики). Если это самостоятельное направление
   для продвижения — выносим в отдельный раздел первого уровня.
2. Канализационные трубы, трапы и воронки положены в «Трубы и фитинги».
   Альтернатива — отдельный раздел «Водоснабжение и канализация».
3. Часть позиций в документах помечена «ТОЛЬКО РИДАН» / «ТОЛЬКО К-ФЛЕКС» —
   подтвердить, что это единственный бренд и других поставок по ним нет.
4. Для 40+ позиций нужны описания (2–4 предложения) и характеристики —
   без них карточки будут пустыми и не будут искаться в поиске.
